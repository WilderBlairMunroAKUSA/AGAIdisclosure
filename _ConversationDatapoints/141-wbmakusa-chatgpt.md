### ✅ Best Practices for Managing API Response Sizes

   - If the API returns extensive information, consider summarizing the data before returning it to the model.

   - Keep track of the number of tokens used in both the prompt and the model's responses to stay within the context window.

If you simply want your **GPT to echo the exact text returned by an external tool call (action)** directly in the chat response, you can easily achieve this with a simple method:

### **💡 How to Make GPT Echo Tool Call Return Text:**

1. **Ensure Your Tool Call Returns Text Directly:**
   - When defining your tool or API action, make sure it returns a **plain text response**.
   - This text should be exactly what you want the GPT to echo.

2. **Modify GPT's Instructions (Prompt Configuration):**
   - In your GPT Builder (ChatGPT UI):
     - Add a specific instruction such as:
       ```
       If a tool call returns text, immediately echo that text in your response without any modifications.
       ```
   - This forces the GPT to use the returned text as its direct response.

3. **Structure Your Tool Call (Action) for Direct Return:**
   - Ensure your tool call is configured to output text in a clean format, such as:
     ```json
     {
       "response": "This is the text returned by the tool."
     }
     ```
   - If the tool returns JSON or a more complex object, make sure the GPT is instructed to extract and echo the specific field you need.

4. **Example Usage:**
   - User: "Perform action \<\<echo_action_response\>\>."
   - Tool (API) Returns: "Hello, this is the response from the tool."
   - GPT Responds: "Hello, this is the response from the tool."

### **🔧 Alternative: Explicit Response Template**
- If you want even more control, you can pre-define a response template for the GPT, such as:
  ```
  Tool Response: {{tool_response_text}}
  ```
- In this case, the GPT will always format the response using this template.
